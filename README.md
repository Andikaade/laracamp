# Mastering Laravel - Learning Management System & Bootcamp Platform

Repositori ini berisi proyek aplikasi **Laracamp** yang dibangun sebagai bagian dari program pembelajaran **BWA Class** (BuildWithAngga). Proyek ini berfokus pada pengembangan platform manajemen kelas atau *bootcamp* berbasis web menggunakan ekosistem Laravel.

---

## 🚀 Fitur yang Dipelajari & Dikembangkan
* **Sistem Autentikasi & Multi-role:** Implementasi login dan pembagian hak akses (User/Siswa dan Admin).
* **Manajemen Kelas/Bootcamp:** Fitur untuk menampilkan daftar kelas, detail program, dan kurikulum.
* **Sistem Transaksi & Checkout:** Alur pendaftaran kelas oleh siswa hingga proses simulasi pembayaran.
* **Dashboard Admin:** Halaman khusus admin untuk memantau data siswa, mengelola transaksi, dan memperbarui status pembayaran.
* **Integrasi Email / Mailtrap:** Pengiriman notifikasi otomatis terkait status transaksi atau pendaftaran.

## 🛠️ Tech Stack & Tools
* **Framework Utama:** Laravel (PHP)
* **Frontend:** Blade Template Engine, Tailwind CSS / Bootstrap (Slicing UI dari materi kelas)
* **Database:** MySQL / PostgreSQL
* **Tools Pengujian:** Mailtrap (untuk simulasi email sandbox)
